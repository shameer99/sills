# `tour`

**Checks:** the first-run tour's rules: steps and targets per layout (landscape leading vertical rail with Apps, Menus and Keyboard; upright single bar with thumbnails, Menus and Keyboard; VoiceOver), what is owed, automatic trigger timing, memory and version-2 upgrade, sessions and reconnects, runs and mid-run rotation carry, crease, width (including Book pose page width and beside-rail width), placement across real devices and folds using `StreamLayout`, and all 64 `TourFeatures` combinations, `"New:"` marks, and VoiceOver copy.

**Compiles:** `iOSClient/TourPolicy.swift` (with `PhonePortraitLayout.swift` and `DuoPosture.swift`)
